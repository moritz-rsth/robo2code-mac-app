Prompt2Robo model duel

One request, one scene, two models. Both write a robot program that runs in its own live MuJoCo simulation (our robot API).

Settings: Hugging Face token & model sources

Pick a model for each side below, or choose Other… and paste a folder path or a Hugging Face link (e.g. https://huggingface.co/Carlo0001/Prompt2Robo-Qwen3-8B-MLX-4bit). It is downloaded on first use. With a token, all Prompt2Robo models of the account moritzzzz appear in both lists (↻ asks Hugging Face again). The public models need no token. The shared copy of the app has a read-only token built in; the GitHub version does not. A token you type here stays in this browser and in the app's memory, it is never written to disk. Models found automatically: mac_app/models and the training output folder.
